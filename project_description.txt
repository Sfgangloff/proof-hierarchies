I want to test rewriting proofs. The idea is the following: if I look at a proof written in lean, there are have statements inside the 
proof. Using these I can reconstruct a proof tree whose nodes are the have statements, and below this node, the subtree corresponding 
to the proof of the have statement. So each level of the tree can be seen as a proof plan to be locally completed. There are of 
course multiple ways to write proofs as such trees, but some of these representations are easier to understand when we read the proofs. 
Aything like minimizing quantiyy of steps or degree of the nodes or things like that.

Motivations: 

- Train a small theorem prover with small resources, or fine-tune existing small model, and see if rewriting the proofs 
has an effect on the model's capacity to prove theorems. 
- Train a model to find a plan for a theorem proof and see if the hierarchical format of proofs has an effect on the efficiency of the model. 
- Build an algorithm which does informalization based on a certain way of writing the proof: it is easier to produce once the proof is written 
in a certain way.
